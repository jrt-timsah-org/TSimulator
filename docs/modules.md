# 機体モジュールとプリセット

F1 →「機体ビルダー」で、5種類のスロットに1つずつモジュールを選びます。候補名をクリックして一覧を開くか、左右ボタンで切り替えます。機体名を入力し、「プリセット保存」で保存、「変更を適用・ラウンド再開」で練習に使用します。

| スロット | 初期候補 | 変更する性能 |
|---|---|---|
| シャーシ | 標準・軽量・大型 | 幅・長さ・高さ・基礎質量 |
| 駆動 | 全方向標準・全方向高速・差動高速・差動安定 | 速度・加速度・旋回・全方向走行 |
| 射出機構 | 標準・連射・高初速・実験用 | 初速・射出高さ・射撃間隔 |
| マガジン | 30・60・90・150枚 | 容量 |
| アーム | 標準・延長・小型 | 前方到達距離・上下限 |

標準機体、高速・連射機、大容量・高初速機、コンテナ運搬機、差動・連射機、自由練習・実験機の6プリセットがあります。連射モジュールは設定間隔0.08秒です。120Hzの判定周期で切り上げた実効間隔は約0.083秒、12発/秒です。パネルのダメージ判定はモジュールとは独立して最大3Hzです。大容量マガジンの初期装填は同盟予備から機体ID順に割り当てるため、後の機体で満装填できない場合があります。サプライで予備を増やし、ピットインで装填できます。

初期モジュールの重量・速度・連射性能は練習用の例です。公式機体やメーカーの性能データではありません。質量は表示・パラメータ検証に使い、慣性・摩擦の剛体モデルには使用していません。外観は簡略化したモジュール表示で、衝突は機体全体の直方体です。HP・ダメージは競技設定で共通です。

## JSON定義

同梱定義は`config/modules/standard.json`にあります。ユーザー領域の`modules/*.json`に次のようなファイルを置き、ビルダーの「モジュール再読込」を押してください。ユーザー領域の実際の場所は設定「CAD・記録」で確認できます。コマンドラインの`--user-data DIRECTORY`で別の保存領域も指定できます。

```json
{
  "schemaVersion": 1,
  "modules": [
    {
      "id": "shooter-custom-rapid",
      "name": "自作・連射機構",
      "slot": "Shooter",
      "description": "初速10m/s、設定間隔0.12秒の練習用射出機構。",
      "addedMassKg": 1.8,
      "parameters": {
        "shotSpeed": 10,
        "shotHeight": 0.1725,
        "shotInterval": 0.12
      }
    }
  ]
}
```

| slot | parametersで指定できるキー |
|---|---|
| Chassis | width, depth, height, massKg |
| Drive | maxSpeed, acceleration, turnSpeed, holonomic |
| Shooter | shotSpeed, shotHeight, shotInterval |
| Magazine | magazineCapacity |
| Arm | armReach, armMinHeight, armMaxHeight |

各モジュールは標準性能へスロット順に適用します。省略したキーは標準性能の値を使います。基礎質量に5モジュールすべての`addedMassKg`を加算します。IDは英数字・ハイフン・アンダースコアで80文字以内。ユーザー定義は同じIDの標準モジュールを上書きできますが、スロットは変更できません。ユーザーファイルはファイル名の順に読み込み、後の定義を優先します。

未知のキー、異なるスロットの性能、重複ID、非有限値、破損したJSONはエラーとして表示します。ユーザーパックにエラーがあると標準パックへ戻し、現在の練習は継続します。パックは最大2MiB・256モジュール、最大128ファイルです。合成した機体の数値検証を通っても、競技条件での外形・質量・射出速度・アーム制限を通らなければ適用できません。実験には自由練習を選んでください。

## 保存と機体別の編集

初期プリセットは`config/robots/*.json`、保存したプリセットはユーザー領域の`robots/*.json`です。プリセットは`id`、`name`、`robot`を持ち、`robot.assembly.modules`に各スロットのIDを保持します。同時に`robot`へ解決済みの全性能を保存します。保存済みのユーザープリセットを選んで再保存すると、そのプリセットを更新します。初期プリセットを保存した場合は新しいユーザープリセットを作ります。

「選択機体」は操縦画面で選択した1台を編集します。「全機体に共通」は機体別設定を解除して全機体へ同じ性能を使います。数値編集も同じ対象を使用します。対戦シナリオを保存すると、`robot`に共通性能、`robotOverrides`に機体IDごとの性能が入ります。モジュール・プリセットを後から変更しても、保存したシナリオとリプレイは保存時の解決済み性能を使います。ビルダーでモジュールを選び直した場合は、現在のモジュール定義から再計算します。

外観・素材の差し替えには`robot.modelPath`を使えます。モジュール選択による再構成は標準の簡略外観へ戻ります。実機の部品配置・電力・通信・センサ・機械リンクの再現はこのモジュール方式の対象外です。
